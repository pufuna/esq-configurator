# Исходные материалы (в сайт не входят)

`drawings/`, `drawings1/` — заводские габаритные чертежи ESQ F ME800 (AutoCAD → PDF): без доп. шкафов
и с шкафом байпаса (ШАБ/ШРБ), с пусковым шкафом (+ПШ). Из них собраны чертежи, которые использует сайт:
`assets/drawings_g1/` (корпус G1) и `assets/drawings_g3/` (корпус G3).

Конфигуратор эти файлы не выбирает ни при одном сочетании параметров (проверено перебором всех моделей,
напряжений, мощностей, типов конденсаторов и доп. шкафов), поэтому они перенесены сюда из `assets/`
и в архив для портала (`tools/build_portal.py`) не попадают. Нужны только для пересборки чертежей G1/G3.
