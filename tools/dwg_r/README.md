# Габаритные чертежи ESQ F ME800-R из DWG производителя

Как получены `assets/drawings_r/*.pdf` — и как пересобрать, если придут новые DWG.

1. **LibreDWG** (чтение DWG): собрать из исходников
   `libredwg-0.13.3.tar.xz` (GitHub releases) → `./configure --disable-bindings && make && make install`.
2. **DWG → JSON:** `dwgread -O json -o json_XX.json XX.dwg` (DXF у части файлов обрывается — JSON надёжнее).
3. **Листы:** `python3 sheets.py XX` — находит рамки листов, пишет `out/XX_sN.svg` и тексты листа.
4. **Чистый лист:** `python3 make_r.py XX <имя>` — только виды и размеры: без штампа, таблицы изменений, рамки
   и мелкого «мусора»; китайские надписи переведены (словарь `TR` в make_r.py), непереведённые — убраны.
   Размеры рисуются по точкам размера (блоки размеров в старых DWG перепутаны).
5. **Дополнительные шкафы:** `python3 compose_r.py <лист> <код> [--bypass-drawn]` — дорисовывает шкаф реактора (R),
   пусковой (S) и байпаса (B): ширина 800 мм, высота и глубина — как у корпуса ПЧ (высота до крыши, без вентиляторов). Внешний вид — как у шкафа байпаса компактной модели
   (лист R_F_10_280-1000_M: фасад и вид сзади), масштабирован под размеры шкафа.
   Фасад: слева от ПЧ, от края — реактор, пусковой, байпас. Вид сзади: справа от ПЧ в зеркальном порядке.
   Виды в плане — прямоугольники ШР/ПШ/ШБ (если слева от вида свободно; на листах F там выноски).
   Файлы: `<лист>_<код>.pdf`, код — B, S, R, BS, BR, SR, BSR (для F — S, R, SR к листам _0/_A/_M).
5а. **Корпус G1 (плёночные вне компактного корпуса: 6 кВ > 630 кВт, 10 кВ > 1000 кВт):** базовый лист
   `python3 make_r.py 08 R_G1 1` (заводской MF5000-G1-10-1600 с шкафом ручного байпаса 650 мм), затем
   `python3 g1.py <Ш> <В> <0|B> [--extras]` — подписи ширины ПЧ и габаритной высоты по таблице РЭ, для «0» шкаф байпаса
   убирается; доп. шкафы — `compose_r.py R_G1_<Ш>_<В>_<0|B> <S|R|SR> --bypass-drawn --body-h 2099`. Всё вместе — `batch_g1.sh`.
   Сочетания Ш×В: 2450×2537, 2450×2767, 2450×2813, 4500×2881 (6 кВ), 4500×2927 (10 кВ); для 4500 вид помечен как условный.
6. **PDF:** `python3 topdf.py out_r/*.svg` (Chromium через Playwright) → лист шириной 420 мм.
